# Guides

Task-oriented pages for embedding and using NativaX.

| Guide | Use when |
|---|---|
| [`embedding.md`](embedding.md) | Adding `NativaXView` or creating a runtime |
| [`resources-and-images.md`](resources-and-images.md) | Loading scripts, CSS, modules, fonts, images, fetch, workers |
| [`forms-and-navigation.md`](forms-and-navigation.md) | Forms, validation, links, dialogs, host navigation |
| [`templates.md`](templates.md) | Rendering app templates into HTML |
| [`examples.md`](examples.md) | Running or judging the examples |
| [`../hot-reload.md`](../hot-reload.md) | Reloading a document during development |
| [`../javascript-supported.md`](../javascript-supported.md) | Checking a browser API before using it |
| [`../css-supported.md`](../css-supported.md) | Checking a CSS feature before relying on it |
| [`../html-supported.md`](../html-supported.md) | Checking parser behavior and limits |

Guides assume the product boundaries in [`../../AGENTS.md`](../../AGENTS.md):
owned rendering, no WebView, real JS engine, and no invented compatibility.
