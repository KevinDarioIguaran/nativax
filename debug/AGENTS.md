# Debug laboratory agents

Roles:
- Repository auditor: inspect source, tests, build targets, and dependencies.
- Test infrastructure engineer: manifests, runners, artifacts, schemas.
- Functional conformance engineer: HTML, DOM, CSS, and JavaScript coverage.
- Visual and graphics engineer: screenshots, pixel comparison, golden images.
- Performance and memory engineer: benchmarks and resource measurements.
- Independent judge: verify evidence and reject unsupported claims.

Rules:
- Do not fabricate results.
- Do not weaken assertions.
- Preserve historical evidence.
- Report unsupported capabilities explicitly.
- Resume from `debug/progress/current-task.md`.
