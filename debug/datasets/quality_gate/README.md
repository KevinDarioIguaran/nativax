# Quality gate snapshot pairs

`pairs.json` holds constructed baseline/current snapshot pairs, each with the
verdict and metric statuses its construction implies. It is generated by
`build_pairs.py`; edit that file and re-run it. `legacy_compare.py` is the
gate's previous comparison, kept verbatim as a reference.

```bash
python3 debug/datasets/quality_gate/build_pairs.py
python3 debug/engines/quality_gate/evaluate_gate.py
python3 debug/engines/quality_gate/test_quality_gate.py
```
